# Sucre Rose – Site vitrine pour pâtisserie

Site exemple d'une pâtisserie fictive à Douala, réalisé pour montrer ce que je peux créer pour un commerce.

## Ce que contient le site :

- Une page d'accueil claire avec un bouton de commande WhatsApp
- La présentation des produits avec leurs prix en FCFA
- Les étapes pour commander
- Les horaires et l'adresse
- Un affichage adapté aux téléphones

## Technologies

HTML et CSS, sans bibliothèque externe. Le site est rapide et léger, ce qui compte avec une connexion limitée.

## Utiliser ce site pour votre commerce

Ce site peut être adapté à votre activité : couleurs, textes, photos, prix et numéro WhatsApp. Il peut aussi être publié avec votre propre nom de domaine.
